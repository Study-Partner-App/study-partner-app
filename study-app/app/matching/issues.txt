## Common Package Manager and Testing Frameworks for Typescript
- packaage manager: npx, buns, etc.
- testing framework: Mocha/Chai

## Types of Tests
- Unit Test - Testing behavior of particular method or component
- Integration Test - Test the edges in between two components
    - Write mock objects that can repalce important components.
- End to End Test - Testing collection of edges. (i.e. test workflow)

## Design
- Test-Driven-Design (TDD) - Fact Test; Write test that so it forces the code to be based on the design model
    - Focuses on code correctness: Does it actually work?
    - Problem: What if you don't have the right mental model?
- Behavior-Driven-Design - Output Test; 
    - Focused on the intended behavior of a component.
    - Looks into: What should happen?

- Instead of having many debugging statements, it can be useful to have test cases baked into the code and remove from final production code.
- It's not good practice to import based on relative path. 
- Since typescript is file-centric, it's better to compile first then test.
